# 2026-11-05 实验一补充：同目标候选差异的多切面复核

本期是对 RUN-020（同目标客户端候选差异）的稳健性补充，回答一个问题：主结论「同一客户端换伙伴的收益差别远大于 KL 预测能力，KL top-1 基本选不到最优」是不是只在某一组切分、某一档异构度、某一种规模下成立。

做法：每次只改一个因素，其余保持主口径（5 epoch、round_1 快照、只聚合 base、CIFAR-10、α=0.3、20 客户端、seed 0），用 `scripts/kl_benefit_distribution.py` 重新生成全候选收益表，再用 `scripts/same_target_candidate_analysis.py` 统计。

| 维度 | 取值 | 客户端 | 数据 |
|---|---|---|---|
| 划分 seed | 0 / 1 / 2 | 20 | CIFAR-10 |
| Dirichlet α | 0.1 / 0.3 / 0.5 | 20 | CIFAR-10 |
| 客户端规模 | 10 / 20 / 50 | — | CIFAR-10 |
| 数据集 | CIFAR-10 / CIFAR-100 | 20 | — |

## 结果

### 1. 三个划分 seed

| 指标 | seed0 | seed1 | seed2 |
|---|---:|---:|---:|
| 可用配对 | 187 | 185 | 86 |
| 可比较目标 | 11 | 11 | 5 |
| 平均 Δacc | −1.11% | −2.76% | +0.80% |
| 负迁移比例 | 65.2% | 71.4% | 61.6% |
| 目标内极差均值 | 12.92% | 9.83% | 11.84% |
| KL top-1 regret 均值 | 5.85% | 5.31% | 9.04% |
| top-1 恰好最优 | 0 / 11 | 0 / 11 | 0 / 5 |
| 目标内 Spearman 均值 | −0.047 | +0.018 | +0.031 |
| 全部混算 Spearman | −0.259 | −0.068 | −0.357 |
| 两跳内目标 | 11 | 11 | 5 |
| 两跳内 regret 均值 | 1.94% | 4.53% | 9.04% |
| 两跳内 top-1 即最优 | 4 / 11 | 1 / 11 | 1 / 5 |

三个 seed 都不出现「KL top-1 命中最优」；regret 在 5–9 pp；混算 Spearman 全为负。

### 2. Dirichlet α（异构度）

| 指标 | α=0.1 | α=0.3 | α=0.5 |
|---|---:|---:|---:|
| 可用配对 | 57 | 187 | 174 |
| 可比较目标 | 3 | 11 | 12 |
| 平均 Δacc | −2.04% | −1.11% | −1.17% |
| 负迁移比例 | 71.9% | 65.2% | 62.1% |
| 目标内极差均值 | 10.66% | 12.92% | 5.67% |
| KL top-1 regret 均值 | 6.20% | 5.85% | 1.42% |
| top-1 恰好最优 | 0 / 3 | 0 / 11 | 2 / 12 |
| 目标内 Spearman 均值 | +0.036 | −0.047 | −0.187 |
| 两跳内 regret 均值 | 1.73% | 1.94% | 0.73% |

越同质（α 越大），候选间极差越小（12.92% → 5.67%），KL 选伙伴越准（regret 5.85% → 1.42%）。α=0.1 退化头太多，只剩 3 个可比较目标，只能当趋势看。

### 3. 客户端规模

| 指标 | 10 客户端 | 20 客户端 | 50 客户端 |
|---|---:|---:|---:|
| 可用配对 | 68 | 187 | 530 |
| 可比较目标 | 8 | 11 | 14 |
| 平均 Δacc | −2.74% | −1.11% | +1.22% |
| 负迁移比例 | 69.1% | 65.2% | 32.8% |
| 目标内极差均值 | 11.71% | 12.92% | 8.00% |
| KL top-1 regret 均值 | 3.44% | 5.85% | 3.04% |
| top-1 恰好最优 | 1 / 8 | 0 / 11 | 2 / 14 |
| 目标内 Spearman 均值 | −0.033 | −0.047 | −0.047 |
| 全部混算 Spearman | +0.093 | −0.259 | −0.094 |
| 两跳内 regret 均值 | 2.70% | 1.94% | 2.51% |

50 客户端的 2450 对里只有 530 对可用，退化头比例高（每个客户端数据只有 20 客户端时的 2/5），这部分只能当规模趋势看，不能和 20 客户端逐项对齐。

### 4. 数据集（CIFAR-100）

| 指标 | CIFAR-10 | CIFAR-100 |
|---|---:|---:|
| 可用配对 | 187 | 378 |
| 可比较目标 | 11 | 20 |
| 平均 Δacc | −1.11% | −2.05% |
| 负迁移比例 | 65.2% | 80.4% |
| 目标内极差均值 | 12.92% | 5.97% |
| KL top-1 regret 均值 | 5.85% | 2.13% |
| top-1 恰好最优 | 0 / 11 | 0 / 20 |
| 目标内 Spearman 均值 | −0.047 | −0.031 |
| 全部混算 Spearman | −0.259 | +0.138 |
| 两跳内 regret 均值 | 1.94% | 1.65% |
| 两跳内 top-1 即最优 | 4 / 11 | 4 / 20 |

CIFAR-100 上结论形态一致：regret 小、top-1 从不命中最优、目标内 Spearman 近似 0。但两者的「小」不是同一件事——CIFAR-10 是极差大而 KL 选错，CIFAR-100 是候选间极差本身就只有 5.97 pp，选错也亏得少。128 维原型把 100 类压得太紧，客户端原型之间的 KL 更难区分收益差异，因此不能把 CIFAR-100 的低 regret 当成「KL 更准」。

## 口径

- 「可比较目标」要求该目标在剔除退化头后仍有 ≥2 个候选、且 Δacc 不全相同；全图口径与两跳内口径分别统计。
- 18 号文档里 seed0 的「两跳内 2.15 pp」是严格口径（额外剔除聚合前后多数类占比 ≥0.9 的配对，152 对）；本表统一用主口径（187 对），seed0 两跳内为 1.94 pp，两者不冲突。
- 规模实验的 10 / 50 客户端各自独立重训了 2 轮 5 epoch 线，只取 round_1 快照，其余配置与主口径一致。

## 结论

- 主结论对划分 seed、异构度、客户端规模都不敏感：KL top-1 很少命中真正最优，regret 稳定在 1–9 pp，目标内 Spearman 在 −0.05 上下浮动。
- 唯一让 KL 变准的是「同质化」：α=0.5 时目标内极差从 12.9 pp 降到 5.7 pp，regret 降到 1.42 pp，仍只有 2/12 命中。
- 规模扩到 50 客户端时目标内极差收窄到 8.0 pp、regret 3.04 pp，但可用配对只剩 530/2450，正迁移比例升到 67%，说明「数据少时怎么聚都涨」，不能当作 KL 变准的证据。
- 换到 CIFAR-100（100 类、20 客户端）结论形态不变：20 个目标全部可比较、top-1 命中 0/20、目标内 Spearman −0.031，regret 2.13 pp（两跳内 1.65 pp）。regret 小是因为候选间极差本身只有 5.97 pp，不是 KL 变准。
- 这支持把结论写成「KL 在同质场景可作为粗筛，在异构场景不能替代实测」，而不是「KL 无效」。
