# 同一目标客户端内的候选差异（5 epoch / round_1 / base / alpha0.1 / seed0）

- 输入：`kl_benefit_srv20_e5_base_a01_s0.csv`
- 配对总数 380，退化 head 剔除 323，过度集中剔除 0，可用 57
- 目标客户端 4 个，其中候选数 ≥2 可比较 3 个，平均每目标 14.2 个候选
- 条件：

## 一、同一目标内，收益差别有多大

- 目标内 Δacc 极差：均值 10.66 pp，中位 13.20 pp
- 可用配对平均 Δacc：-2.04 pp，负迁移比例 71.9%

## 二、KL 规则选中的伙伴是不是最好的

- 事后最优与 KL top-1 的差距（regret）：均值 +6.20 pp，中位 +4.79 pp，最大 +9.80 pp
- KL top-1 恰好就是最优的 target：0 / 3
- KL top-1 优于 KL 第二名的 target：0 / 3
- 目标内 KL 与 Δacc 的 Spearman：均值 +0.036，中位 0.026，为负的 target 1 / 3
- 全部配对混算的 Spearman：-0.035（仅供对照，不作为结论）

## 六、边界

- 单伙伴、单轮聚合：不是原方法的多伙伴集合，不能当作在线效果。
- 同一目标的多个候选不独立，所有统计先按目标聚合，再取均值。
- 图距离是快照邻接图上的最短路径长度，不等于多跳转发次数。
- 结论只覆盖该快照的条件（轮次、种子、聚合范围）；跨种子或跨轮次需另行重复。
