## 一、同一目标内，收益差别有多大

- 目标内 Δacc 极差：均值 9.83 pp，中位 8.18 pp
- 可用配对平均 Δacc：-2.76 pp，负迁移比例 71.4%

## 二、KL 规则选中的伙伴是不是最好的

- 事后最优与 KL top-1 的差距（regret）：均值 +5.31 pp，中位 +3.80 pp，最大 +22.20 pp
- KL top-1 恰好就是最优的 target：0 / 11
- KL top-1 优于 KL 第二名的 target：6 / 11
- 目标内 KL 与 Δacc 的 Spearman：均值 +0.018，中位 0.032，为负的 target 5 / 11
- 全部配对混算的 Spearman：-0.068（仅供对照，不作为结论）

## 六、边界

- 单伙伴、单轮聚合：不是原方法的多伙伴集合，不能当作在线效果。
- 同一目标的多个候选不独立，所有统计先按目标聚合，再取均值。
- 图距离是快照邻接图上的最短路径长度，不等于多跳转发次数。
- 结论只覆盖该快照的条件（轮次、种子、聚合范围）；跨种子或跨轮次需另行重复。
