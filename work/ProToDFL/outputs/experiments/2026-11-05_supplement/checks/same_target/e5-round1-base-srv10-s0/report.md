# 同一目标客户端内的候选差异（5 epoch / round_1 / base / 10 clients / seed0）

- 输入：`kl_benefit_srv10_e5_base_s0.csv`
- 配对总数 90，退化 head 剔除 22，过度集中剔除 0，可用 68
- 目标客户端 8 个，其中候选数 ≥2 可比较 8 个，平均每目标 8.5 个候选
- 条件：

## 一、同一目标内，收益差别有多大

- 目标内 Δacc 极差：均值 11.71 pp，中位 7.64 pp
- 可用配对平均 Δacc：-2.74 pp，负迁移比例 69.1%

## 二、KL 规则选中的伙伴是不是最好的

- 事后最优与 KL top-1 的差距（regret）：均值 +3.44 pp，中位 +2.60 pp，最大 +14.00 pp
- KL top-1 恰好就是最优的 target：1 / 8
- KL top-1 优于 KL 第二名的 target：3 / 8
- 目标内 KL 与 Δacc 的 Spearman：均值 -0.033，中位 -0.217，为负的 target 5 / 8
- 全部配对混算的 Spearman：0.093（仅供对照，不作为结论）

## 六、边界

- 单伙伴、单轮聚合：不是原方法的多伙伴集合，不能当作在线效果。
- 同一目标的多个候选不独立，所有统计先按目标聚合，再取均值。
- 图距离是快照邻接图上的最短路径长度，不等于多跳转发次数。
- 结论只覆盖该快照的条件（轮次、种子、聚合范围）；跨种子或跨轮次需另行重复。
