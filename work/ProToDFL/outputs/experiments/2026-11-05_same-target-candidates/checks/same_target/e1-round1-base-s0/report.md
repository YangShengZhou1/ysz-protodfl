# 同一目标客户端内的候选差异（1 epoch / round_1 / base / seed0）

- 输入：`kl_benefit_clean.csv`
- 配对总数 380，退化 head 剔除 347，过度集中剔除 0，可用 33
- 目标客户端 2 个，其中候选数 ≥2 可比较 2 个，平均每目标 16.5 个候选
- 条件：CIFAR-10, 20 clients, Dirichlet 0.3, ResNet-18, 1 local epoch, single-partner aggregation on base only, snapshot paired20-base-s0/round_1

## 一、同一目标内，收益差别有多大

- 目标内 Δacc 极差：均值 19.07 pp，中位 19.07 pp
- 可用配对平均 Δacc：+7.85 pp，负迁移比例 24.2%

## 二、KL 规则选中的伙伴是不是最好的

- 事后最优与 KL top-1 的差距（regret）：均值 +13.08 pp，中位 +13.08 pp，最大 +14.80 pp
- KL top-1 恰好就是最优的 target：0 / 2
- KL top-1 优于 KL 第二名的 target：1 / 2
- 目标内 KL 与 Δacc 的 Spearman：均值 +0.289，中位 0.289，为负的 target 0 / 2
- 全部配对混算的 Spearman：0.433（仅供对照，不作为结论）

## 六、边界

- 单伙伴、单轮聚合：不是原方法的多伙伴集合，不能当作在线效果。
- 同一目标的多个候选不独立，所有统计先按目标聚合，再取均值。
- 图距离是快照邻接图上的最短路径长度，不等于多跳转发次数。
- 结论只覆盖该快照的条件（轮次、种子、聚合范围）；跨种子或跨轮次需另行重复。
